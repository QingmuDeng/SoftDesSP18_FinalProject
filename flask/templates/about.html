Our Purpose

Generate web safe color palettes from inputted images using color theory, k means clustering, and machine learning. Our goal is to extract usefulness from your favorite images by providing user-friendly tools, such as downloadable color palettes, web page generation, and image sentiment analysis. Color Palette
Generation

You can generate color palettes just by uploading an image from the home page. Additional color palettes can be created by selecting a particular region of the image using the crop feature or choosing different types of color palettes (i.e. complementary and analogous). The output palette is shown in an interactive format, which displays a color’s hex and rgb values on hover.
